# Game of Advisors

**Thesis is coming!**

Eine Plattform zur Vermittlung von Studierenden und passenden Betreuer:innen für Abschlussarbeiten an der Heinrich-Heine-Universität Düsseldorf.

## About

Game of Advisors soll die Suche nach einer geeigneten Betreuungsperson und einem passenden Thema für die Abschlussarbeit vereinfachen.

Die Plattform bündelt Betreuer:innenprofile, Forschungsschwerpunkte und Themenvorschläge an einem zentralen Ort.

**Die ursprüngliche Projektidee und Aufgabenstellung stammen aus dem ProPra der Heinrich-Heine-Universität Düsseldorf:**

[ProPra – Game of Advisors](https://propra.d.stups.hhu.de/ws26/4bc13d67e16022c/index.html)

## Features

- **Betreuer:innenprofile:** Zentrale Profile mit Kontaktinformationen, Interessengebieten und zusätzlichen Ressourcen.
- **Themenübersicht:** Veröffentlichung und Durchsuchen möglicher Abschlussarbeitsthemen.
- **Filter & Suche:** Finden von Personen und Themen anhand fachlicher Interessen.
- **Matching:** Vorschläge auf Basis eigener Interessen und bereits bestandener Veranstaltungen.
- **Rollenverwaltung:** Getrennte Berechtigungen für Studierende, Betreuende und Administrator:innen.

## Tech Stack

- **Language:** Java
- **Framework:** Spring Boot
- **Build:** Gradle
- **Architecture:** Onion Architecture
- **Authentication:** HHU GitLab
- **Deployment:** Docker & Docker Compose
